# Harbor Hospital Operations — Project 2

## Overview
Harbor Hospital Operations is a fictional hospital operations dashboard developed for an academic Red Hat/Open Source project.

The application currently demonstrates:
- Hospital operations overview
- Patient coordination
- Admissions
- Bed-board and ward-capacity monitoring
- Care teams
- Appointments
- Billing and payments
- Reports
- Messages
- Settings

## Billing & Payments
The Billing & Payments module includes fictional:
- Outstanding balances
- Payments received
- Insurance claims
- Overdue invoices
- Invoice and payment status
- Revenue-cycle workflow
- Billing alerts
- Record Payment form

All patient, clinical, billing, insurance, invoice, and payment information is fictional and is intended only for an academic demonstration.

## Run Locally
Open `index.html` in a modern web browser.

No server, database, or external dependency is required for this baseline version.

## Project 2 Roadmap
This baseline application will be progressively extended with:
1. Podman containerization
2. Source control
3. CI/CD
4. Kubernetes / Red Hat OpenShift deployment
5. Service and network configuration
6. Prometheus and Grafana monitoring

## Academic Purpose
The goal is to demonstrate how open-source and Red Hat technologies can support an end-to-end application workflow rather than presenting each infrastructure component as an isolated exercise.

Do not enter or store real patient, clinical, or financial information in this demonstration application.
